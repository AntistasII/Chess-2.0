# Android: автономные шахматы с картами

Android 8.0 и новее. Правила, карты, локальный ИИ и интерфейс находятся в APK.
Веб-сервер, Railway и компьютер для игры не нужны. Приложение не слушает сетевые порты.

- Локальный ИИ и два игрока на одном устройстве работают без интернета.
- ChatGPT — дополнительный онлайн-соперник. Нужны интернет и собственный ключ OpenAI.
  Ввод ключа находится в окне новой партии; ключ шифруется Android Keystore и
  не попадает в APK или файл партии. Запросы OpenAI оплачиваются отдельно.
- После каждого успешного действия партия автоматически записывается в приватное хранилище.
  После закрытия и повторного запуска приложения восстанавливается текущая позиция.
- «Сохранить» и «Продолжить» используют отдельное ручное сохранение.
- Экспорт и импорт JSON-файлов партии используют стандартный выбор документов Android.
  Разрешение на доступ ко всему хранилищу не требуется.
- Сетевой игры с другом в этой сборке нет. Она остаётся в версии Railway.

## Сборка

Нужны JDK 21, Node.js/npm, Python 3, Android SDK Platform 35 и Build Tools 35.0.0.

```sh
sh scripts/android-build.sh
```

SDK: `.tools/android-sdk` либо `ANDROID_HOME`. Gradle и его кэш находятся в `.tools/gradle-user`.
Скрипт собирает интерфейс, APK и запускает Android Lint.
Результат: `artifacts/chess-android.apk` — установочный APK с отладочной подписью,
не релиз для Google Play. Android может попросить разрешить установку из выбранного источника.
Обновление поверх старой установки требует той же подписи. Сохраните
`.tools/android-user/debug.keystore`, чтобы выпускать совместимые обновления.

## Общий движок

`prepare-build.py` подготавливает Android-совместимые исходники из `backend/src/main/java/chess`.
Правила, фигуры, карты и поиск ИИ не копируются вручную и не расходятся с настольной версией.
Адаптации: регистрация аннотированных карт без Spring-сканирования, совместимые Java API,
транспорт OpenAI средствами Android. Общие игровые настройки берутся только из встроенного
`backend/src/main/resources/application.yml`. Локальный корневой `application.yml` с ключом
никогда не читается при упаковке; значение `api-key` в упакованных настройках всегда пустое.

Интерфейс упаковывается из `frontend/dist`. `android.js` передаёт команды Java-движку внутри
процесса асинхронно. Адрес `https://appassets.androidplatform.net/` обслуживается из APK,
а не через интернет. Автосохранение выполняется до ответа интерфейсу и переживает завершение процесса.

Проект открывается в Android Studio как папка `android`.

## Проверка

На отдельном Android 15 ARM64 эмуляторе проверены: локальный поиск ИИ, игра вдвоём,
добор карт, ручное сохранение/загрузка, четыре направления расширения с сохранением фигур,
запрет щита на короля, шах через белую дыру, восстановление после завершения процесса,
отсутствие ключа в экспорте, экспорт через системный выбор документов.
Локальная игра дополнительно проверена с запретом исходящего IPv4/IPv6 для UID приложения.
Реальные платные запросы к OpenAI во время проверки не выполняются.

Для повторной проверки на уже запущенном отдельном эмуляторе с установленным debug APK:

```sh
ANDROID_SERIAL=emulator-5556 node scripts/android-smoke.mjs
```

Проверка заменяет партию только на эмуляторе; на физических устройствах скрипт отказывается работать.
Дополнительная копия итоговой сборки: `artifacts/chess-offline.apk`.
